# Decision entry (template for [[Decisions Log]])

Newest first. One entry per decision or delivery that changed how the game is or how we work.

```markdown
### <YYYY-MM-DD> — <what was decided, in a few words> (<who: user / Claude / both>)
- **What:** <the decision or delivery, with the numbers that matter>.
- **Why:** <the reason; the user's own words in quotes where there are any>.
- **Then:** <later changes, if any: "on hold (user, <date>)">.
- **Where:** <owner notes, files, the asset's NOTE.md>.
```
